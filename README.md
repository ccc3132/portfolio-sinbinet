# portfolio-sinbinet

**(주)오경컴텍** 재직 중 협업사 **(주)신비넷** 제품을 대상으로 수행한 업무 포트폴리오입니다.

- 소속: (주)오경컴텍
- 협업사: [(주)신비넷](http://www.sinbinet.com/)
- 재직 기간: 2019.01 ~ 2021.01
- 역할: IoT 제품 기능 검증용 테스트 프로그램(Java GUI) 개발

## 담당 업무 요약

IoT 센서·게이트웨이 제품의 기능을 검증하기 위한 **Java GUI 테스트 프로그램**을 개발했습니다.

| 제품 | 제품 설명 | 폴더 |
|---|---|---|
| 환경 모니터링 | 환경 데이터(온습도, 산소·이산화탄소 농도 등) 수집·분석 시스템 | [products/environment-monitoring](products/environment-monitoring) |
| 위치 태그 | 작업자·자산 위치 파악용 태그(BLE, NFC 등 지원) | [products/location-tag](products/location-tag) |
| 온습도 센서 | 온습도를 측정해 게이트웨이로 전송하는 센서 | [products/temp-humidity-sensor](products/temp-humidity-sensor) |
| 온습도 게이트웨이 | 온습도를 표시하고 서버로 전송하는 게이트웨이 | [products/temp-humidity-gateway](products/temp-humidity-gateway) |

## 사용 기술

- Java, JavaFX (GUI)
- 통신: TCP/IP

## 참고

- 회사 내부 소스코드와 비공개 자료는 포함하지 않았으며, 업무 내용과 역할 위주로 정리했습니다.
