# 환경 모니터링 테스트 프로그램

## 제품 개요
- 온도, 습도, 산소·이산화탄소 농도 등 환경 데이터를 수집·저장·분석하여 보여주는 모니터링 시스템 (예: 온습도 모니터링)
- 출처: [(주)신비넷 홈페이지](http://www.sinbinet.com/) 내용을 요약

## 담당 업무
- 제품 기능 검증용 Java GUI 테스트 프로그램 개발

## 테스트 프로그램 기능
- TCP/IP로 제품과 통신하며 기능을 검증하는 JavaFX 테스트 프로그램

## 사용 기술
- Java, JavaFX, TCP/IP 통신
